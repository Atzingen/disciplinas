# Imagens de referência do manual AZEHEB

As imagens desta pasta foram extraídas de **Manual de Experiências — Kit
Eletromagnetismo Básico**, AZEHEB, revisão 12, de 20/11/2020, arquivo local
`67001.0043_CONJ_DE_ELETROMAGNETISMO_BASIC.pdf`.

O aviso da página 1 permite que instituições de ensino reproduzam partes do
manual para uso em laboratório, sem finalidade de venda. O PDF completo não é
redistribuído neste repositório; cada página usa somente as fotografias úteis à
montagem didática e mantém o crédito `Fonte: manual AZEHEB`.
