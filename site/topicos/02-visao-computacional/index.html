Visão computacional

Da imagem como matriz à câmera como instrumento de medida. Uma sequência para entender o algoritmo, experimentar com dados reais e discutir o que o resultado significa.

O percurso

Escolha um capítulo nos cards abaixo. Comece pelos pixels e avance até os modelos que aprendem. Cada capítulo reúne explicação, código e uma pergunta para investigar. Os exemplos de imagem usam a mesma bolinha que depois aparece no experimento do pêndulo.

  3. 03Convolução e redes neuraisConvolução, MNIST, Fashion-MNIST e cães/gatos: código e resultados na página.Abrir capítulo →
  4. 04Detecção, segmentação e embarcadosYOLO, caixas, máscaras, rastreamento e inferência em dispositivos embarcados.Abrir capítulo →

Preparar o ambiente

As demonstrações desta página funcionam no navegador. Para os scripts com janela ou webcam, use Python no computador. Os notebooks podem ser abertos no Jupyter ou enviados ao Google Colab por Arquivo → Fazer upload de notebook.

Obter os arquivos

Na cópia deste repositório, entre em site/topicos/02-visao-computacional. Os comandos dos exemplos partem dessa pasta. Ao baixar arquivos individualmente, preserve as subpastas scripts/, imagens/, videos/ e dados/; os links de cada capítulo indicam suas entradas.

python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements-imagem.txt
python scripts/01_imagem.py

Instale só o percurso que vai usar:

  • Imagem: OpenCV e NumPy.
  • Medida: acrescenta SciPy e Matplotlib.
  • Redes neurais: dependências dos notebooks.
  • Detecção e segmentação: YOLO no computador; a preparação dos embarcados está no capítulo 4.

Use q para encerrar os vídeos; os exemplos de imagem fixa fecham com uma tecla. A leitura de webcam depende da câmera e da permissão do sistema. O primeiro uso de um dataset nos notebooks requer internet.

De onde vem este material

Esta sequência adapta o acervo de visão computacional aplicada à física e seleciona exemplos dos cursos SAMBA 2022, Webinar de visão embarcada e FIC de Inteligência Artificial. Os vídeos vêm do experimento de rastreamento do pêndulo.

Guia de arquivos e procedência. O capítulo 4 traz também as referências de formigas e de visão embarcada.
